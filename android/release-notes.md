## AI5 런처 v0.9

elf AI5WIN 게임(한글판·일본판)과 **꽃과뱀(花と蛇)** 한글패치판을 안드로이드에서 실행하는 런처입니다.

### 설치
아래 Assets에서 `ai5-launcher.apk`를 받아 설치하세요(v0.8 위에 덮어 설치 가능). 게임 파일은 들어 있지 않으니, 가지고 계신 게임 폴더를 폰에 복사한 뒤 런처에서 고르세요.

### 이번 버전에서 바뀐 것 (기존 지원작 검수)
- **취작**
  - 배경 음악이 하나도 안 나오던 문제 수정 (음악 파일 끝이 잘린 경우 그 곡만 빼고 재생)
  - 음성이 하나도 안 나오던 문제 수정 (압축 음성 IMA ADPCM 재생)
  - 이름 입력: "한글" 판에서 한글 이름을 넣을 수 있음 (전에는 □로 깨짐), 5글자 뒤 → 화살표를 누르면 꺼지던 문제 수정
  - 일기(저장) 시간이 "[토요일오후궯궯시]"처럼 깨지던 문제 수정
- **동급생2 한글판**: 행동 이름표(보다·조사, 말하다, 열다 …)가 일본어로 나오던 문제 수정
- **게임 종료 확인 창**을 한국어로

### 검수 내용
- 유작: 장면 280개 전부 바로 시작 시험, 본편 → 구교사 진행, 저장/불러오기, 복도 이동·방 출입 확인
- 취작: 토요일 오후 ~ 일요일 진행, 저장/불러오기 확인
- 동급생2: 방 → 거실 → 마을 지도, 잠자기 저장/불러오기 확인

### 알려진 문제
- 꽃과뱀은 저장 기록이 없으면 원본처럼 타이틀 없이 프롤로그부터 시작합니다.
- 취작 가운데 클릭 메뉴는 가상 버튼 "메뉴"로 여세요.
