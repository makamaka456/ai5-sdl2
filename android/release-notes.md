## AI5 런처 v0.5

elf AI5WIN 게임(한글판·일본판)과 **꽃과뱀(花と蛇)** 한글패치판을 안드로이드에서 실행하는 런처입니다.

### 설치
아래 Assets에서 `ai5-launcher.apk`를 받아 설치하세요. 게임 파일은 들어 있지 않으니, 가지고 계신 게임 폴더를 폰에 복사한 뒤 런처에서 [폴더 추가]로 고르세요.

### 꽃과뱀
- 타이틀부터 엔딩까지 진행 (공략 경로·인물 엔딩 12개·하렘 엔딩 자동 시험에서 오류 없음)
- 걷는 지도(1인칭 복도 이동, 작은 평면도, 조사 지점), 방 조사, 선택지, 조교 화면, 도구 획득
- 저장/불러오기(원본과 같은 저장 파일 형식), 지난 대사, 용어 사전, 환경 설정, 오프닝 영상
- 여흥 메뉴(음악·그림·장면·엔딩 회상) — 런처 [설정]에서 처음부터 모두 열기 가능

### 이번 버전에서 고친 것 (원본과 나란히 비교)
- 지도 복도 그림이 위아래로 뒤집혀 보이던 것
- 화면이 번쩍인 뒤 장면 그림이 바뀌어 버리던 것 (프롤로그 등)
- 불러온 뒤 복도에 서 있던 인물이 사라지던 것
- 장면이 바뀌어도 인물이 화면에 남아 있던 것
- 지하·1층 이동 명령이 서로 바뀌어 있던 것

### 알려진 문제
- 조교 미니게임은 아직 없음 (항상 자동 진행)
- 장면 안에서 불려 나온 작은 장면 도중에 저장/불러오기 하면 그 장면이 끝날 때 게임이 끝날 수 있음
