## AI5 런처 v0.7

elf AI5WIN 게임(한글판·일본판)과 **꽃과뱀(花と蛇)** 한글패치판을 안드로이드에서 실행하는 런처입니다.

### 설치
아래 Assets에서 `ai5-launcher.apk`를 받아 설치하세요(v0.6 위에 덮어 설치 가능). 게임 파일은 들어 있지 않으니, 가지고 계신 게임 폴더를 폰에 복사한 뒤 런처에서 고르세요.

### 이번 버전에서 바뀐 것
- **꽃과뱀 조교 미니게임**: 원본의 밧줄 게임·과녁 게임을 원본대로 만들었습니다. 도구 고르기 화면에서 "미니게임: 직접/자동"을 고를 수 있고, 한국어 조작 설명이 있습니다.
- **유작 아이템 창**: 본편 시작 때 아이템 창이 켜진 채로 화면이 멈춘 것처럼 되던 문제를 고쳤습니다. 원본처럼 게임 화면을 누르면 아이템 창이 뒤로 가려지고 진행되며, "아이템" 버튼으로 다시 불러옵니다.
- **취작 폴더 지정 때 틀린 경고**("AI5WIN.EXE가 없습니다")가 뜨던 것 수정
- 일부 그림의 투명 부분이 어긋나 보이던 문제 수정 (꽃과뱀 도구 획득 창 등)

### 알려진 문제
- 꽃과뱀은 저장 기록이 없으면 원본처럼 타이틀 없이 프롤로그부터 시작합니다(한 번 저장하거나 타이틀로 돌아가면 다음부터 타이틀).
- 꽃과뱀: 장면 안에서 불려 나온 작은 장면 도중에 저장/불러오기 하면 그 장면이 끝날 때 게임이 끝날 수 있음
